## 🎯 Visión General

VicWithGG Portfolio es un sitio web personal profesional construido desde cero para presentar proyectos, experiencia y competencias como Diseñador UX/UI y Desarrollador Web Frontend. El reto no era solo crear un portafolio "bonito" — era diseñar y desarrollar un producto técnico que demostrara por sí mismo las capacidades que anuncia: rendimiento, accesibilidad, SEO técnico y código limpio.

> **Rol:** UX/UI Designer + Frontend Developer (proyecto propio)
> **Duración:** 2022 – Presente (versión actual con Astro 6, actualizada abril 2026)
> **Contexto:** Proyecto personal · Marca propia VGG Desarrollo y Diseño

---

## 💡 Solución Clave

- **SSG con Astro 6:** El sitio se genera completamente estático en build time, logrando tiempos de carga mínimos sin sacrificar interactividad donde se necesita — el patrón correcto para un portafolio de contenido.
- **Content Collections con MDX:** Cada proyecto se gestiona como un archivo `.mdx` con schema Zod validado, separando el contenido de la presentación y haciendo el sistema escalable sin tocar código.
- **Diseño de sistema propio:** Paleta oscura con acentos dorados y azules, tipografía premium auto-hospedada (Barlow Condensed, IBM Plex Mono, Inter, Onest) y tokens de diseño personalizados en Tailwind v4 — sin usar templates de terceros.
- **Búsqueda estática con Pagefind:** Indexación automática post-build que permite buscar proyectos y experiencia sin backend, sin costos de servidor y con cero latencia.
- **SEO + accesibilidad production-grade:** JSON-LD structured data, Open Graph dinámico, sitemap con prioridades, canonical URLs, skip links, ARIA labels y contraste WCAG AA — el mismo estándar que se aplica a proyectos de clientes.

## ⚙️ Stack Técnico

| Tecnología                | Propósito                                                       |
| ------------------------- | --------------------------------------------------------------- |
| Astro 6                   | Framework SSG · renderizado estático ultra-rápido               |
| TypeScript 5              | Tipado estático en componentes, schemas y configuración         |
| Tailwind CSS v4           | Utility-first styling con tokens de diseño personalizados       |
| MDX + Content Collections | Gestión de proyectos como contenido estructurado con schema Zod |
| React (isla)              | Componentes interactivos opcionales dentro de Astro             |
| Pagefind                  | Búsqueda estática en el sitio, generada en post-build           |
| @astrojs/sitemap          | Sitemap XML automático con prioridades por tipo de página       |
| @astrojs/rss              | Feed RSS de proyectos destacados                                |
| Vercel                    | Hosting · CDN global · Analytics · Image Optimization           |
| Vite                      | Build tool con code splitting y minificación con esbuild        |
| Prettier + CI             | Formato de código automatizado y validación en cada PR          |

## 📊 Resultados

- **12+ proyectos** documentados y presentados en el portafolio, cubriendo diseño UX/UI, apps web y design systems.
- **Rendimiento Lighthouse ≥ 95** en desktop gracias a SSG, imágenes AVIF/WebP, fonts auto-hospedadas con preload y code splitting por vendors.
- **SEO técnico completo:** sitemap XML, JSON-LD, Open Graph, Twitter Cards, canonical URLs y RSS feed — el mismo stack que proyectos de producción enterprise.
- **Accesibilidad WCAG AA** verificada: navegación por teclado completa, skip links, focus indicators visibles y contraste auditado en toda la paleta.
- **CI automatizado** con GitHub Actions que valida typecheck + build en cada Pull Request, garantizando que ningún deploy rompa el sitio.
- **Deploys continuos** en Vercel con CDN global — cada push a `main` actualiza el sitio en segundos sin intervención manual.
- **Sistema de contenido escalable:** agregar un nuevo proyecto requiere solo crear un archivo `.mdx` — sin modificar código, sin tocar componentes.
